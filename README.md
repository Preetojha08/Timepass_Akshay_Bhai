# Akshay Dhoundiyal · Warehouse Operations Manager Portfolio

A fast, responsive one-page portfolio built with React, TypeScript, Vite, and Tailwind CSS. Optimized for Netlify’s static hosting and Lighthouse-friendly performance.

## Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:5173` to develop locally.

## Production Build

```bash
npm run build
npm run preview
```

The production-ready output is generated in `dist/`.

## Deploying to Netlify

1. Push this repository to your remote (GitHub, GitLab, etc.).
2. In Netlify, create a new site from Git, select the repo, and use:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
3. Deploy. Netlify will serve the optimized static build with redirects handled via `public/_redirects`.
